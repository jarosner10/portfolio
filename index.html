Projects

Apex Solutions Database Design

A relational database I built in Oracle SQL for a fictional live events and ticketing company as part of my ISA 345 final project. It includes ten normalized tables covering artists, venues, events, customers, orders, tickets, payments, employees, payroll, and shifts, connected with primary and foreign keys to enforce referential integrity. I also wrote a PL/SQL trigger that automatically assigns the next available ticket to a new order, and populated the schema with realistic sample data to test the design.
